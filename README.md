# chatwick-app

Мини-приложение Telegram для бота [@ChatwickBot](https://t.me/ChatwickBot): игры, профиль, рейтинги.

Только вёрстка: один `index.html` и шрифты. Никаких данных игроков здесь нет.
Бот передаёт данные игрока в части адреса после `#` — она не отправляется на хостинг и читается только на телефоне игрока.
Шрифты Inter и Lora (SIL Open Font License) лежат в `fonts/`, к сторонним сайтам страница не обращается.
